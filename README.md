# rakutama-lp-Tokyo

楽珠そろばん教室（東京・練馬区）のランディングページ。

---

## 改修履歴

### 2026-04-08 — LP/campaign.html: 各校カードにGoogleマップ埋め込みを追加

**変更内容**
- 早宮校・氷川台校・中村校の各教室カードに `<iframe>` でGoogleマップを埋め込み（height: 180px / width: 100%）
- 従来の「Googleマップで見る」リンクを「大きな地図で見る」に変更し、埋め込み地図の下に配置
- 各マップリンクに GA4 `click_map` イベントトラッキングを追加（`school: 'hayamiya'` 等）

**理由**
Microsoft Clarityのセッション録画で、InstagramからLPへ流入したユーザーが「Googleマップで見る」リンクを複数回クリックし外部遷移していることが判明。立地への関心が高い一方、外部遷移による離脱リスクが存在していた。ページを離れずに地図を確認できる埋め込み形式に変更し、滞在時間の向上と離脱率の低下を狙う。

### 2026-04-08 — access.html: 各校セクションにGoogleマップ埋め込みを追加

**変更内容**
- 早宮校・氷川台校・中村校の各セクションに `<iframe>` でGoogleマップを埋め込み（height: 200px / width: 100%）
- 「Googleマップで見る」リンクを「大きな地図で見る」に変更し、埋め込み地図の下に配置

**理由**
LP/campaign.html と同じ立地関心への対応。アクセスページは立地確認を目的に訪れるユーザーが多いため、外部遷移なしに地図を閲覧できる体験を提供する。
